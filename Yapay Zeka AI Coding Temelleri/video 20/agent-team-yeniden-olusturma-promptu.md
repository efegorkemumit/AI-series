# Agent Team'i Yeniden Oluşturma Promptu

Bu proje için Agent Team'i yeniden oluştur.

Sen Team Lead olarak kal.

Şu project-level agent tiplerini teammate olarak başlat:

- `planner` → agent tipi: `planner`
- `ui` → agent tipi: `ui-designer`
- `backend` → agent tipi: `backend-developer`
- `qa` → agent tipi: `qa-reviewer`

Önceki bölümde Planner tarafından oluşturulmuş Shared Task List'i kullan.

- Yeni plan oluşturma.
- Yeni task oluşturma.
- Mevcut task'ları değiştirme.
- Henüz implementasyona başlama.
- Hiçbir dosyada değişiklik yapma.

Sadece dört teammate'i yeniden oluştur, mevcut Shared Task List'i kontrol et ve takımın hazır olduğunu kısa şekilde bildir.
